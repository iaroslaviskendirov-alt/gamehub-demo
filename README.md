# Демо-сайт для GameHub

Сайт компьютерного клуба: залы с характеристиками и ценами и онлайн-бронирование.
Клиент выбирает зал, тариф, дату, время и число мест, нажимает «Забронировать в WhatsApp»,
и в WhatsApp приходит готовая заявка с итоговой суммой. Весь сайт — один файл `index.html`.

## 1. Вписать свой номер WhatsApp (обязательно перед отправкой)
1. Правой кнопкой по `index.html` → «Открыть с помощью» → «Блокнот».
2. Ctrl + F → найдите `whatsapp: '77000000000'`.
3. Замените на свой номер: только цифры, начиная с 7. Например, `whatsapp: '77011234567'`.
4. Ctrl + S.

Номер клуба (+7 777 353 98 13) вписываем **только после согласия владельца**.

## 2. Выложить в интернет
1. Откройте **app.netlify.com/drop**.
2. Перетащите туда всю папку `gamehub-demo`.
3. Получите ссылку и зарегистрируйтесь (бесплатно), чтобы сайт не удалился через час.
4. Проверьте ссылку на своём телефоне.

## 3. Поменять цены или залы
В начале скрипта в `index.html` есть блок `CONFIG`: залы (`zones`), тарифы (`tariffs`) и цены (`prices`).
Меняйте только текст в кавычках и числа.

## Откуда данные
Цены, залы, характеристики ПК, адрес и режим работы взяты из карточки клуба в 2ГИС
(раздел «Цены» обновлён 2 августа 2026). Перед отправкой их стоит сверить ещё раз.
